# Frostbyte Arcade

A mobile-first mini game hub with four playable games:

- Arctic Drift: ice driving, checkpoints, boost, and score chasing.
- Connect 4: local two-player mode plus a simple arcade AI.
- Circuit Snake: fast score-run snake with persistent best score.
- Memory Rush: compact matching game with move and best-score tracking.

## Run Locally

This is a static app. Start any local static server from the repo root:

```bash
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.
